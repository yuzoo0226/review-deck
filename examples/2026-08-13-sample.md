# サンプル報告: Review Deck の使い方

これは動作確認用のサンプル報告です。本文をドラッグ選択すると「💬 コメントする」が出ます。

## コメントの付け方

1. 気になる文をドラッグで選択する
2. 「💬 コメントする」を押してコメントを書く（Ctrl/Cmd+Enter で保存）
3. コメントした箇所は黄色くハイライトされ、右のマージンに一覧が並ぶ

## レビューを返す

ヘッダの「レビューを Claude に返す」を押すと、未対応コメントが
`/review-comments` 形式にまとまり、送り先の Claude Code セッション（tmux 内）へ注入できます。

```mermaid
graph LR
  A[Claude が報告を書く] --> B[reports.json に登録]
  B --> C[ブラウザでレビュー]
  C --> D[レビューを Claude に返す]
  D --> A
```

確認が済んだら、このファイルと reports.json のサンプルエントリは消して構いません。
